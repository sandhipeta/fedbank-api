# FedBank fake API (json-server)

Fake Federal Bank customer data (1000 customers) for Postman practice.
All data is fake (emails end in mockfedbank.com).

## Render settings
- Build Command: `npm install`
- Start Command: `npm start`
- Instance type: Free

## Endpoint
`https://<your-service>.onrender.com/customers`

Note: `npm start` uses Linux shell syntax (for Render).
To run on your own Windows PC, use: `npx json-server db.json`
